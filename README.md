# EnergyFlow

EnergyFlow is a web application for monitoring and predicting renewable energy production using machine learning.

## Features

- Real-time energy production monitoring
- ML-based predictions for different energy sources
- Interactive dashboards
- PDF report generation
- Responsive design

## Technologies

- React
- TypeScript
- Vite
- TailwindCSS
- Recharts
- Machine Learning (Python)

## Installation

```bash
# Clone the repository
git clone https://github.com/AoufNihed/EnergyFlow.git

# Navigate to project directory
cd EnergyFlow/project

# Install dependencies
npm install

# Start development server
npm run dev
```

## Deployment

```bash
# Build and deploy to GitHub Pages
npm run deploy
```
